# 互联网粗野主义设计规范

状态：Phase 0 规范草案，仅定义原则与初始参数；未创建 CSS、组件或完整视觉页面。Phase 1 以实际页面检验并调整参数，再记录确认结果。

## 视觉原则

像一份独立实验刊物：黑白高对比、大字号、明显网格与边框、直接的语言和信息层级。粗野主义不等于故意难用：论文必须易读、链接必须可辨、操作必须可达。避免装饰性渐变、厚重阴影、过多圆角和无意义动画。

品牌可以夸张，内容证据必须克制。视觉不伪装成权威期刊认证，也不把“模拟”“虚构”等标签藏入低对比角落。

## 色彩约定

以下名称是文档中的变量约定，Phase 1 再写入代码：

| 名称 | 初始色值 | 用途与限制 |
| --- | --- | --- |
| 背景 | `#FFFFFF` | 默认页面和长文背景 |
| 主墨色 | `#111111` | 正文、标题、边框 |
| 次级墨色 | `#4A4A4A` | 次要说明，仍需清晰可读 |
| 强调红 | `#C40000` | 白底链接、重点或小面积标记；不要用作黑底小字 |
| 可选荧光黄 | `#E6FF00` | 与深色文字搭配的小面积底色；不作为白底正文色 |

默认一页只选一种强调色，避免红黄同时争夺注意。白底红字与黄底黑字的实际组合需测量对比度。状态、真实性和链接同时使用文字、下划线、边框或图形提示，不能只靠颜色。

## 字体与文字层级

- 中文优先系统字体：`system-ui`、`"Microsoft YaHei"`、`"PingFang SC"`、无衬线回退。代码采用系统等宽字体；初版不依赖外部字体服务。
- 正文字号初定 `1.125rem`，最低 `1rem`；辅助文字通常不小于 `0.875rem`。尊重浏览器的根字号，不用缩放整页压缩内容。
- 正文行高约 1.7–1.9，标题约 1.05–1.25。品牌大标题计划用响应式字号，长中文标题必须换行，不能溢出手机屏幕。
- 阅读栏初定不超过约 42 个中文字符宽或 72 个西文字符宽；中文与西文的度量不同，需分别验证，不能仅照搬 `ch` 值。
- 一级标题说明本页主旨；正文按逻辑使用二、三级标题，不因视觉效果跳过语义层级。正文避免通篇大写、字距过密或超重字重。

## 网格、边框与间距

整体内容最大宽度初定约 `80rem`，长文阅读栏单独限制。手机一列，平板可分两列，桌面允许 12 列网格但按内容组合。网格用来建立秩序，不要求每个区域都硬塞满列。

间距初定为 `0.25 / 0.5 / 0.75 / 1 / 1.5 / 2 / 3 / 4rem`；同类元素使用一致节奏。手机两侧至少约 `1rem` 留白。细分隔线 1px，重要结构边框 2–4px；不用所有文字都围框的方式增加噪声。

## 响应式约束

- 从手机单列开始；建议在约 `48rem` 和 `72rem` 观察是否需要切换布局，断点由真实内容决定。
- 320 CSS 像素宽下正文与导航应可重排；长 URL、论文标题和标签不撑开页面。表格、代码和数学公式确需横向空间时，限制在局部区域滚动。
- 图片不超过容器宽度；有表达意义的图片需要文字说明。导航换行或以可操作的控件展开，不用不可点击的小字挤满一行。
- 200% 字体放大与桌面 400% 缩放后保留内容及操作；不把固定高度作为长文本容器。

宽度目标依据 [W3C 重排说明](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html)，将在 Phase 1/4 实测，当前不是已通过的测试结果。

## 无障碍与长文阅读

- 正文对比度至少 4.5:1，大号文字至少 3:1，依据 [W3C 最低对比度说明](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)。交互边界与焦点也应足够明显。
- 链接保留下划线等可辨识线索，键盘焦点清晰可见；不删除浏览器焦点轮廓后不提供替代。
- 使用正确的 `lang`、语义化主内容/导航/标题、必要的表单标签；装饰图隐藏于辅助技术，内容图提供合适替代文本。
- 触摸操作区域以约 44×44 CSS 像素为设计目标；正文中的行内链接按阅读场景处理，不能为追求网格而挤在一起。
- 不自动播放或持续闪烁；尊重减少动态效果的系统设置。首版优先无动画。
- 论文需要可选中文本、可复制代码、可辨引用与有说明的真实性标签。公式、目录和打印样式属于 Phase 3，再做实际验证。

## Phase 1 落地顺序

先建立少量 CSS 变量和基础排版，再做共享外壳、导航/页脚与页面骨架，最后用长标题、键盘操作和手机宽度检验。品牌图标替换必须同时更新引用；现有 Astro 图标在替换前保留，避免断链。本阶段不产出首页或真实论文。
